# Makeables-2025-3D-Printed-Braille-Keyboard
A product submission for the Makeables 2025 contest. Won dual categories in both "Iterative Design" and "Best Use of 3D Printing"

This project is fully open source, you are welcome to take it and improve on it. All necessary components to recreate the project can be found in ProjectFiles.pdf and Team 7 - Bill of Materials and Assembly Process.pdf
